# No Process Porn

`no-process-porn` catches agent workflows that accumulate impressive-looking process while the requested capability remains missing. It distinguishes useful controls from ceremony by asking what consumes them and what action changes, then redirects the work into implementation, a bounded diagnostic, proportionate verification, demotion, routing, subtraction, or an honest hold.

Good fits:

- "Promoted," "ready," "green," "verified," or "complete" overstates the evidence
- Gates, ledgers, manifests, dashboards, reports, or handoffs have no downstream consumer
- A smoke test is being treated as proof of more than it exercised
- Permanent instrumentation is proposed for a one-time diagnosis
- Fresh-eyes reviews, completion audits, or agent swarms keep producing meta-work
- Issue closure, commits, test counts, or reviewer findings are becoming proxy rewards
- A workflow needs permission to return `NO DISTINCT FINDING`

It does not reject process by keyword. Safety controls, real release gates, temporary diagnostic probes, operational telemetry, compliance records, and explicitly requested process work remain valid when their consumers and consequences are clear.
