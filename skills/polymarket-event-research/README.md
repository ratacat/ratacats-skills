# Polymarket Event Research

This skill is for price-blind research on how a Polymarket-style event would actually resolve.

Use it when the user wants the real-world path: offices, courts, agencies, deadlines, procedures, proof standards, local context, and the facts that would make a market resolve Yes or No. It avoids odds, prices, volume, holders, and trading talk.

Many markets look simple until the resolution rule touches a messy institution. This skill helps the agent trace the path from headline to resolver without getting distracted by market movement. Family role: use `pm-situation-framing` to frame the situation, `polymarket-event-research` for one event's resolution machinery, `pm-deep-analysis` for broader price-blind research and likelihood tables, and `pm-market-analysis` for market-aware work.

Good fits:

- Understanding resolution mechanics for one Polymarket-style event
- Finding the source authority that would prove the outcome
- Explaining legal, procedural, or local paths
- Mapping actors, institutions, proof channels, and veto points
- Preparing a world-context handoff for later market analysis
