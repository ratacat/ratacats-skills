# julian-writing

Julian Shapiro's *Writing Well* handbook, condensed into a method an agent can follow. The handbook's own advice was used to write it: short sentences, one idea each, before-and-after examples, nothing you'd cut.

The framework is one line: writing quality = novelty × resonance. The first draft finds novel ideas. Every draft after makes them resonate.

Good fits:

- Essays, blog posts, articles, handbooks, newsletters, threads
- Writing an intro that earns the rest of the read
- Rewriting a bloated draft for clarity, succinctness, and intrigue
- Reviewing a draft with a reader's score instead of a vibe

Not for code comments, API docs, or marketing copy.
